# Main repo for the quaro repo

## Structure

Two main branches

1. remote: Contains all the packages used remotly. 
    - `quaro_description`. 
    - `quaro_messages`.
2. local: Contains all the packages to run locally on the raspberry pi. 
    - `quaro_messages`
    - `quaro_interface`
